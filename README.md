# Social posting kit (Cookshipcreatives)
Used by the daily-ad-posting skill. Not part of the website.
- render.js + overlay.html + fonts + cookie.webp: renders an ad with the 4 platform overlays.
- posted.json: log of every ad posted, per platform. Never post an ad that is already here.
- SKILL.md: latest copy of the daily-ad-posting skill. The installed skill is read-only for the user, so scheduled tasks are told to follow THIS file where it differs from the installed one.
